# STM32 智能循迹小车（两层闭环控制）

> **项目状态（2026-10）**：速度环 PI、显式状态机、FreeRTOS 运行时验证（调度器 / 时基 / 电机·编码器·灰度回归 / 多任务时间片轮转）均已实测通过，控制逻辑已重构为独立 RTOS 任务；位置环循迹参数在标准场地适配中（灰度模块为固定阈值，需白底黑线场地）；OLED 驱动代码已完成、待新屏实测。实车跑完整赛道待验证。

基于 STM32F103C8T6 独立开发的两轮差速闭环循迹小车。核心是**两层控制闭环**：

- **速度环（内环）**：编码器测速 + PI 控制，让左右轮精确达到目标转速
- **位置环（外环）**：8 路灰度循迹，根据黑线位置动态分配左右目标转速，实现差速转向

运行在 **FreeRTOS V9.0.0** 上：运行时验证（调度器 / 时基 / 外设回归 / 多任务轮转）通过后，控制逻辑已从裸机主循环搬进独立任务（`vTaskDelayUntil` 锁 10ms 周期）。

通过该实践掌握：嵌入式软件分层架构（BSP/App）、PWM 调速、定时器编码器测速、PID 整定、显式状态机、FreeRTOS 任务划分、VOFA+ 上位机调参、实时性与踩坑排查。

## 实测验证（2026-08 ~ 2026-10）

- **速度环已实测调通**：闭环自动补偿两电机死区差异（左轮启动 PWM>600、右轮>400），消除纯 P 控制稳态静差
- **状态机已实测验证**：全黑/全白哨兵值优先判定避免电机失控；按键原地恢复运行
- **串口实时性修复验证**：修复 printf 阻塞拖垮 10ms 控制节拍导致速度环正反馈失控的问题
- **FreeRTOS 运行时验证通过**：调度器启动、时基递增、电机 / 编码器 / 灰度三项外设回归、多任务时间片轮转
- **控制任务重构已验收**：控制逻辑搬入 `controlTask`，功能回归通过；10ms 节拍锁定（100 拍 = 1000 tick，IDLE / RUN 态均无漂移）
- **位置环循迹**：参数整定中，需白底黑线标准场地验证

## 系统架构

```
      位置环(外环)                 速度环(内环)
 灰度 pos ──→ 左右目标速度 ──→ PI ──→ PWM ──→ 电机 ──→ 编码器 ──→ 测速
      ▲                                                 │
      └──────────────────── 反馈 ──────────────────────────┘
```

## 软件分层

| 层 | 文件 | 职责 |

| 主程序 | `main.c` | 初始化 + 创建控制任务 + 启动调度器 |

## 技术要点

- 定时器编码器模式（TIM2/TIM4，4 倍频，1040 脉冲/圈，10ms 采样测速）
- 位置环 P + 速度环 PI 串级差速控制，积分 / 目标 / PWM 三重限幅防饱和
- IDLE / RUN / LOST / CROSS 显式状态机（10ms 调度）
- VOFA+ 上位机曲线调参（FireWater CSV）
- FreeRTOS V9.0.0（RVDS/ARM_CM3 port，heap_4）：控制逻辑运行在独立任务，`vTaskDelayUntil` 锁 10ms 周期；中断向量表已交内核接管
- 硬件细节：TB6612 换向安全时序、CD4051 切换 50us 稳定延时、编码器引脚上拉、I2C1 重映射避让

## 硬件

- 主控：STM32F103C8T6
- 驱动：TB6612 双路（D153C）
- 电机：MG310 直流减速电机（霍尔编码器，13 线，减速比 20）
- 传感器：8 路数字灰度（CD4051 选通 + LM393 比较）
- 供电：12V 锂电池 → DCP3512（12V 电机 / 5V 主控与灰度，分路供电）
