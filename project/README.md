# STM32 智能循迹小车（两层闭环控制）

基于 STM32F103C8T6 的两轮差速闭环循迹小车。核心是**两层控制闭环**：

- **速度环（内环）**：编码器测速 + PI 控制，让左右轮精确达到目标转速
- **位置环（外环）**：8 路灰度循迹，根据黑线位置动态分配左右目标转速，实现差速转向

通过该实践掌握：嵌入式软件分层架构（BSP/App）、PWM 调速、定时器编码器测速、PID 控制、
VOFA+ 调参、串口调试、踩坑排查。

## 系统架构

```
      位置环(外环)                 速度环(内环)
灰度 pos ──→ 左右目标速度 ──→ PI ──→ PWM ──→ 电机 ──→ 编码器 ──→ 测速
     ▲                                                 │
     └──────────────────── 反馈 ──────────────────────────┘
```

## 硬件

- 主控：STM32F103C8T6
- 驱动：TB6612 双路（D153C）
- 电机：MG310 直流减速电机（霍尔编码器，13 线，减速比 20）
- 传感器：8 路数字灰度

## 引脚分配

| 模块 | 信号 | 引脚 |
|---|---|---|
| 左电机 | PWMA / AIN1 / AIN2 | PB1 / PB10 / PB11 |
| 右电机 | PWMB / BIN1 / BIN2 | PB0 / PB12 / PB13 |
| 灰度 | AD0 / AD1 / AD2 / OUT | PA2 / PA3 / PA4 / PA5 |
| 左编码器 | A相 / B相 | PA1 / PA0 (TIM2) |
| 右编码器 | A相 / B相 | PB6 / PB7 (TIM4) |
| 串口 | TX / RX | PA9 / PA10 (USART1) |

## 软件分层

| 层 | 文件 | 职责 |
|---|---|---|
| BSP 驱动 | `bsp_motor.c` | 电机 PWM + 方向 |
| BSP 驱动 | `bsp_gray.c` | 8 路灰度读取、位置计算 |
| BSP 驱动 | `bsp_encoder.c` | 编码器测速 |
| App 控制 | `app.c` | 位置环 + 速度环 PID |
| 主程序 | `main.c` | 主循环闭环调度 |

## 技术要点

- 定时器编码器模式（TIM2/TIM4，4 倍频）
- 两轮差速循迹（内环速度 PI + 外环位置 P）
- 积分限幅、PWM 限幅防饱和
- 增量式测速（10ms 采样，脉冲差 → RPM）
- VOFA+ 上位机曲线调参
