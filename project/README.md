# STM32 智能循迹小车（两层闭环控制）

> **项目状态（2026-09）**：速度环 PI 与显式状态机已实测调通；位置环循迹参数在标准场地适配中（灰度模块为固定阈值，需白底黑线场地）；OLED 驱动代码已完成、待新屏实测。项目持续迭代中，规划接入 DMA 串口、定时器中断节拍并扩展更多外设。

基于 STM32F103C8T6 独立开发的两轮差速闭环循迹小车。核心是**两层控制闭环**：

- **速度环（内环）**：编码器测速 + PI 控制，让左右轮精确达到目标转速
- **位置环（外环）**：8 路灰度循迹，根据黑线位置动态分配左右目标转速，实现差速转向

通过该实践掌握：嵌入式软件分层架构（BSP/App）、PWM 调速、定时器编码器测速、PID 整定、显式状态机、VOFA+ 上位机调参、实时性与踩坑排查。

## 实测验证（2026-08 ~ 2026-09）

- ✅ **速度环已实测调通**：闭环自动补偿两电机死区差异（左轮启动 PWM>600、右轮>400），消除纯 P 控制稳态静差
- ✅ **状态机已实测验证**：全黑/全白哨兵值优先判定避免电机失控；按键原地恢复运行
- ✅ **串口实时性修复验证**：修复 printf 阻塞拖垮 10ms 控制节拍导致速度环正反馈失控的问题
- ⏳ **位置环循迹**：参数整定中，需白底黑线标准场地验证

## 系统架构

```
      位置环(外环)                 速度环(内环)
 灰度 pos ──→ 左右目标速度 ──→ PI ──→ PWM ──→ 电机 ──→ 编码器 ──→ 测速
      ▲                                                 │
      └──────────────────── 反馈 ──────────────────────────┘
```

## 软件分层

| 层 | 文件 | 职责 |
|---|---|---|
| BSP 驱动 | `bsp_motor.c` / `bsp_motor.h` | TB6612 电机 PWM + 方向安全时序 |
| BSP 驱动 | `bsp_gray.c` / `bsp_gray.h` | 8 路灰度读取、加权位置计算 |
| BSP 驱动 | `bsp_encoder.c` / `bsp_encoder.h` | 定时器编码器测速（RPM） |
| BSP 驱动 | `bsp_key.c` / `bsp_key.h` | 非阻塞去抖 + 沿检测按键 |
| BSP 驱动 | `bsp_oled.c` / `bsp_oled.h` | SSD1306 I2C OLED 驱动 |
| App 控制 | `app.c` / `app.h` | 位置环 + 速度环 PID、状态机 |
| 主程序 | `main.c` | 仅初始化 + 10ms 主循环调度 |

## 技术要点

- 定时器编码器模式（TIM2/TIM4，4 倍频，1040 脉冲/圈，10ms 采样测速）
- 位置环 P + 速度环 PI 串级差速控制，积分 / 目标 / PWM 三重限幅防饱和
- IDLE / RUN / LOST / CROSS 显式状态机（10ms 调度）
- VOFA+ 上位机曲线调参（FireWater CSV）
- 硬件细节：TB6612 换向安全时序、CD4051 切换 50us 稳定延时、编码器引脚上拉、I2C1 重映射避让

## 硬件

- 主控：STM32F103C8T6
- 驱动：TB6612 双路（D153C）
- 电机：MG310 直流减速电机（霍尔编码器，13 线，减速比 20）
- 传感器：8 路数字灰度（CD4051 选通 + LM393 比较）
- 供电：12V 锂电池 → DCP3512（12V 电机 / 5V 主控与灰度，分路供电）
