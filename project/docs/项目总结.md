# STM32 智能循迹小车 —— 项目总结

> 更新：2026-09-12
> 定位：独立开发，作为嵌入式软件方向的能力证明
> 代码：`../code/smart/`（Keil MDK 工程，Target: f103）

## 一、项目概述

基于 STM32F103C8T6（Cortex-M3）独立搭建并开发的两轮差速循迹小车，
实现「位置环 P + 速度环 PI」串级双闭环控制。目标不只是拼模块跑起来，
而是用分层架构、显式状态机、实时性意识和闭环控制，把一辆车从零**调通**。

## 二、项目目标与范围

- **主线**：从零搭建一辆「速度环调通、能循迹」的小车，覆盖 驱动 → 控制 → 实时性 → 调试 全链路
- **工程化**：BSP/App 分层、模块化驱动、规范提交、完整技术文档
- **实时性**：10ms 控制节拍稳定，不被 IO 阻塞破坏
- **边界**：不追求花哨功能，把单个方向做到深度可讲

| 模块 | 说明 |

## 四、软件架构

按 BSP（驱动层）/ App（应用层）两层组织，`main.c` 只保留初始化与 10ms 主循环：

```
BSP 驱动层：bsp_motor / bsp_gray / bsp_encoder / bsp_key / bsp_oled
App 应用层：app.c（位置环 + 速度环 + 状态机）
main.c    ：初始化 + 10ms 节拍调度
```

自写代码约 1000+ 行（不含 HAL 驱动库），分 13 个源文件。

## 五、核心实现

### 1. 串级双闭环控制
- **位置环（外环）**：`Gray_GetPosition()` 返回黑线位置 pos（-7000~+7000，哨兵值 9999/-9999），
  P 控制算出左右轮目标转速差，实现差速转向
- **速度环（内环）**：编码器 10ms 采样 → RPM，PI 控制达到目标转速
- **三重视限幅防饱和**：积分限幅 2000、目标限幅（40~200）、PWM 限幅 7200

### 2. 显式状态机（IDLE / RUN / LOST / CROSS，10ms 调度）
- IDLE：上电默认停车，200ms 屏蔽按键防上电误触，按 PA8 进 RUN
- RUN：正常压线跑位置环；全白 → LOST，全黑 → CROSS
- LOST / CROSS：进入当拍 `App_Stop()` 清目标积分 + `Motor_BrakeAll()` 短接刹车，并用 `s_brake` 标志保持刹车态（速度环短路不再输出，避免覆盖）；按 PA8 原地恢复，无需断电重启
- 关键：全白/全黑**先判 ±9999 哨兵值再进位置环**，避免异常值被当作极大偏差驱动电机疯转

### 3. 实时性处理
- **修复 printf 阻塞**：`fputc` 原用 `HAL_MAX_DELAY` 无限等待，串口变慢时把 10ms 节拍拖到
  数百 ms，速度环采样间隔不稳形成正反馈、电机失控反转；改为 50ms 超时 + 打印限频 500ms

### 4. 硬件相关细节
- TB6612 换向遵循「关 PWM → 改方向 → 恢复 PWM」，避免绕组电感电流突变产生数倍堵转电流尖峰
- CD4051 通道切换后保留 50us 等 LM393 比较器稳定（缺失时实测通道 1/5 互换误读）
- 编码器引脚改上拉输入，抑制信号线虚接时计数乱跳
- I2C1 重映射至 PB8/PB9，避让右编码器占用的 PB6/PB7

## 八、踩坑总结（22 项，详见 调试记录.md）

按类别归纳：

- **接线/接触类（最常见：#4 #7 #10 #11）**：杜邦线内部断、AD0/AD2 接反、编码器 A/B 接反、面包板虚接
  → 学会用「交换测试 / 交叉验证」定位
- **电源类（#5）**：供电反接烧驱动板 → 先量电源轨短路再上电
- **流程类（#19 #20）**：printf 阻塞拖垮控制节拍、改完代码忘了烧录——问题往往不在想查的那一层 → 养成"验收先确认烧录版本、复现最先做"的习惯
- **程序/工程（#2 #3 #8 #15）**：Keil 插件终端、缺 stdio.h、main 少 `}`、VSCode 工程打开方式
- **硬件个体差异（#6）**：电机死区不同 → 闭环 PID 自动补偿
- **控制参数（#12 #13）**：低速量化误差放大 → Kp 50→15；纯 P 静差 → 加 Ki
- **实时性（#19）**：printf 阻塞破坏节拍 → 超时 + 限频
- **外设时序（#7）**：CD4051 切换 50us 稳定延时
