# 项目参数

## 编码器

- 电机：MG310 直流减速电机，霍尔编码器，13 线，减速比 20
- 编码器模式：定时器编码器模式，4 倍频（TI12）
- 每圈脉冲数（车轮转 1 圈）：20 × 13 × 4 = 1040，代码里是 ENCODER_PULSE_PER_REV
- 采样周期：10ms（ENCODER_SAMPLE_MS）
- 测速换算：RPM = 脉冲数 / 采样周期 × 60 / 1040

## 位置环（外环，循迹）

定义在 app.c 里。

- KP = 1，位置环比例系数
- BASE_SPEED = 150，基础目标速度（RPM）
- TARGET_MIN = 100，目标速度下限，防止慢速轮太低
- TARGET_MAX = 200，目标速度上限
- MAX_STEER = 50，最大转向量（归一化后）

转向量这么算：steer = KP * (pos / 7000) * MAX_STEER，把 pos 归一到 -1~1。左右目标就是 target_left = BASE_SPEED + steer，target_right = BASE_SPEED - steer。

灰度位置 pos 范围 -7000~+7000，0 居中，负偏左，正偏右；9999 是全白丢线，-9999 是全黑。

## 速度环（内环，PI）

- PID_KP = 15，比例系数
- PID_KI = 1，积分系数
- INTEGRAL_MAX = 2000，积分限幅，防积分饱和
- PWM_LIMIT = 7200，PWM 限幅

速度环一开始 Kp 给的 50，固定 150 目标时挺稳，但位置环一把目标改了就震荡，降到 15 才好。这个踩坑过程调试记录里有。

## 电机

- 驱动：TB6612 双路（D153C）
- PWM 范围：0~7200（MOTOR_PWM_MAX），频率约 10kHz
- Motor_SetSpeed(motor, speed)：speed 正/负/零对应正转/反转/停止，内部限幅 ±7200

## 串口

- 波特率 115200，USART1，TX=PA9，RX=PA10
- VOFA+ 用 FireWater 协议，printf("%d,%d\n", ...) 纯 CSV 格式（带标签会只出一个通道）

## OLED

- 屏：0.96 寸 SSD1306，128x64，4 针 I2C，地址 0x3C
- 接口：硬件 I2C1 重映射，SCL=PB8，SDA=PB9
- 刷新周期：100ms 一次（main 主循环里 OLED_REFRESH_MS）
- 坐标：一行 0~3（每行高 16 像素），一列 0~15（每字宽 8 像素）
- 显示内容：状态（RUN/LOST/CROSS/STOP）、左右目标速度、左右实测速度、位置偏差 pos

## 按键（bsp_key.c）

- 引脚：PA8，上拉输入（GPIO_PULLUP），按下接地
- 去抖时间：KEY_WAIT_MS = 50ms，电平稳定 50ms 才确认变化
- 检测方式：非阻塞沿检测，Key_Scan() 返回"刚按下"边沿（一次点击返 1）
- 上电防抖：状态机 IDLE 里上电 200ms 内忽略按键（s_boot_time）

## 状态机（app.c）

- 状态：IDLE（待机停车）/ RUN（循迹）/ LOST（丢线停车）/ CROSS（十字停车）
- 调度节拍：每 10ms 一次（App_State_Update，与速度环采样同拍）
- 转移：
  - IDLE → RUN：按 PA8（上电 200ms 后）
  - RUN → LOST：灰度全白（pos == 9999）
  - RUN → CROSS：灰度全黑（pos == -9999）
  - LOST / CROSS → RUN：按 PA8（手动恢复，不用断电重启）
- 停车策略：LOST/CROSS 刚进入时 Motor_BrakeAll() 快速刹车一次；停留期间 target=0，速度环维持静止
