# 模块说明

工程按驱动层和应用层分了两层。驱动层（BSP）管硬件，应用层（App）管控制逻辑，main.c 只做初始化和主循环。

## 分层

- 驱动层（BSP）：电机、灰度、编码器，每样一个文件
- 应用层（App）：位置环和速度环的控制逻辑都在这里
- main.c：只做初始化和主循环，控制逻辑都交给 app 层

## 各模块

### 电机驱动 bsp_motor.c/h

控制两个直流减速电机的速度和方向，用的是 TB6612 双路驱动。

- Motor_Init()：初始化 PWM，启动顺序是安全的
- Motor_SetSpeed(motor, speed)：设置某个电机的速度，speed 为正转、负反转、0 停，范围 -7200~+7200
- Motor_Stop() / Motor_Brake() / Motor_StopAll()

换方向要按"先关 PWM → 改方向 → 再恢复 PWM"的顺序。不然绕组电感电流不能突变，直接翻方向会产生好几倍堵转电流的尖峰，管子会发热、电源会被拉低。

### 灰度传感器 bsp_gray.c/h

读 8 路数字灰度，算出黑线偏离中线的位置（加权平均）。

- Gray_GetPosition()：返回黑线位置 -7000~+7000，0 是居中，负是偏左，正是偏右；9999 是全白丢线，-9999 是全黑

这个模块用 CD4051 模拟开关选通道，切换通道后必须等 50us 再读，不然 LM393 比较器还没稳定，读出来是错的。我试过把延时注释掉，通道 1 和 5 就互换了。

### 编码器 bsp_encoder.c/h

用定时器编码器模式测左右轮转速（RPM）。

- Encoder_Init()：启动 TIM2/TIM4 编码器计数
- Encoder_GetCount_Left()/Right()：读某轮脉冲数（带符号），读完清零
- Encoder_UpdateSpeed()：每 10ms 采样算一次速度
- Encoder_GetSpeed_Left()/Right()：返回某轮 RPM

参数：4 倍频（TI12），每圈脉冲数 = 减速比 20 × 线数 13 × 4 = 1040。左编码器接 TIM2（A=PA1, B=PA0），右编码器接 TIM4（A=PB6, B=PB7）。左编码器 A/B 相接反过，会导致方向反，这个在调试记录里写了。

### 控制层 app.c/h

两层闭环控制都在这里。

- 位置环（外环）App_Position_Control()：读灰度 pos，用 P 控制算出左右轮的目标速度（RPM），靠左右速度不同来实现差速转弯。
- 速度环（内环）Speed_Control()：用编码器反馈的实际转速，PI 控制让左右轮达到目标速度。

积分做了限幅防饱和，目标速度也做了限幅，PWM 同样限幅。不然积分积多了会过冲，低速轮会抖。

## 控制架构示意

```
位置环(外环)                速度环(内环)
灰度 pos ──→ 左右目标速度 ──→ PI ──→ PWM ──→ 电机 ──→ 编码器 ──→ 测速
   ▲                                                 │
   └─────────────────── 反馈 ──────────────────────────┘
```
