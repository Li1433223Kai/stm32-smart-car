# 调试记录

从零开始做这个项目，踩了不少坑。按时间顺序记一下，大部分都是不起眼的小问题，但每个都值得记。

## 8.16

问题：很久没碰 STM32，重新拿出 C8T6，写个点 PC13 的程序没反应。
排查：程序没问题，接线正常，试别的程序也不行。点了下 debug，居然有现象了。
原因：太久没用 Keil，忘了 download，一直在 rebuild，根本没烧录进去。
解决：记得烧录程序。

## 8.17

问题：VSCode 里用不了 Keil 插件。
排查：检查 UV4 路径，换工程文件夹，都没用。问别人才知道要在"资源管理器大纲"下面的"Keil UVision Project"目录打开工程文件。
原因：一直在操作 VSCode 自己打开的那个文件。
解决：在资源管理器大纲里找到 Keil UVision Project 目录打开工程。

问题：Keil Assistant 一点 build 就报 bash: syntax error near unexpected token '&'。
排查：看终端路径发现是 Git Bash 在执行，但 Keil Assistant 生成的命令是 PowerShell 语法（那个 & 调用运算符）。
原因：VSCode 默认终端设成了 Git Bash。
解决：把默认终端改成 PowerShell。

问题：下载报 ST-LINK USB communication error。
排查：设备管理器能看到 ST-Link，Keil Settings 里能看到序列号和固件版本，说明 USB 和驱动没问题。但 SW Device 显示 No target connected。检查 ioc 里 PA13/PA14 是 Serial_Wire 没被占用，板子电源也亮，SWDIO/SWCLK/GND/3.3V 接线也没错。降时钟到 100kHz、under Reset 模式按复位键，还是不行。最后换了根杜邦线就好了。
原因：杜邦线内部断了，外表看不出来。
解决：换杜邦线。

## 8.19

问题：上电没反应，电机驱动板不亮。
排查：看芯片外观没发黑，用万用表蜂鸣档量 VM 和 GND，响了（短路了）。
原因：不小心把供电反接了，把驱动板击穿了。
解决：买了个新的驱动板。

## 8.21

问题：低 PWM 下左轮几乎不动，右轮正常。
排查：先排除代码，Motor_SetSpeed 两个电机逻辑对称没写错。查接线，AIN1/AIN2/PWMA 对应左轮，BIN1/BIN2/PWMB 对应右轮，也对。悬空测试给两个电机相同 PWM，左轮还是慢。再把左右电机线在驱动板端互换，原来慢的还是慢。
原因：直流减速电机个体差异，死区不同。左轮 PWM>600 才启动，右轮 PWM>400 就启动，给 500 时左轮卡着不动。
解决：正常现象非 bug。开环给 PWM>1500。加了编码器闭环 PID 后，PID 发现左轮没到目标转速会自动调大左轮 PWM，差异被补偿。

## 8.23

问题：灰度模块数据不对，串口打印 8 路和实际不符，挡第一个灯结果第五个亮，变成 51372648。
排查：查代码，怀疑接线，发现 AD0 和 AD2 接反了。改过来还是不对，1 和 5 是反的。再查代码，发现 Gray_ReadChannel 里的延时被注释掉了，切换通道后没等稳定就读。
原因：切换通道后没延时，读取不稳定。
解决：保留切换后的 50us 延时。

## 8.24

问题：改了主循环报 function definition is not allowed here。
排查：检查代码，main() 的 {} 没闭合，少了个 }。
原因：main 的右括号没封闭，把 while 后的函数都包进 main 里了。
解决：在 while 结束后补一个 }。

问题：循迹一启动就往右转。
排查：多次试都往右。发现是灰度模块 8 号灯一直常亮。把模块放白纸上测，8 号灯灭了。
原因：家里地板不够白，跟黑线区分不开。
解决：暂未解决。这个模块不能调阈值（买的时候没注意），打算到学校用那边的场地。

## 8.25

问题：重组小车后左轮转右轮不转。
排查：左轮正常说明供电没问题。查右轮 BIN1/BIN2/PWMB 引脚正常。查代码左右轮同时 set compare 也没问题。后来看到右轮 BIN 接的 PB0、PB1 在板子末尾，想到换了新面包板可能没插紧。
原因：板子没插稳。
解决：重新插稳。

问题：加编码器后速度出现负值，方向反了。
排查：用串口看编码器计数，正转时计数是负的。查接线，发现左编码器 A 相、B 相接反了（A 接到 B，B 接到 A）。
原因：编码器 A/B 相接反，导致计数方向反。
解决：对调 A/B（A=PA1、B=PA0），方向恢复。

## 8.27

问题：速度环 Kp=50 时稳定在 150，但位置环一变速就剧烈震荡。
排查：位置环给左右不同目标后，慢速那侧轮子剧烈震荡、转速乱跳。把 Kp 从 50 降到 15，再调 Ki 才稳定。
原因：Kp 对变速/低速场景偏大。低速时编码器脉冲少，量化误差被放大，PID 就震荡了。
解决：Kp 降到 15，Ki 调到 1。

问题：速度环稳定后高速/低速轮存在静差（实际低于目标）。
排查：纯 P 控制有稳态误差，因为 PWM=Kp*err，要维持转速就得有非零 err。
原因：P 控制固有稳态误差。
解决：加大 Ki 用积分项消除，静差没了。

问题：VOFA+ 只识别到一个通道，应该左右两个。
排查：先 printf 带名字 left:%d,right:%d，只出一个通道。改成纯 CSV %d,%d\n 后正常出两个。
原因：VOFA+ FireWater 要纯 CSV（逗号分隔、不带标签），带标签会被解析成一个通道。
解决：printf 用 %d,%d\n 纯 CSV 格式。

问题：printf 报 implicitly declaring library function。
排查：在 app.c 里用了 printf，没 include stdio.h。
原因：缺 stdio.h。
解决：app.c 加 include stdio.h。
