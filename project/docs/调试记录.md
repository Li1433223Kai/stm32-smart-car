3.问题：keil assistant点build，终端报 bash: syntax error near unexpected token `&'
调试过程：看终端路径发现是Git Bash在执行，而keil assistant生成的命令用的是PowerShell语法（&调用运算符），bash不认识
原因：vscode默认终端设成了Git Bash，keil assistant只能用PowerShell或cmd
解决：Ctrl+Shift+P -> Terminal: Select Default Profile -> 选PowerShell，关掉旧终端重新build

4.问题：下载报 ST-LINK USB communication error，Flash Download failed - Target DLL has been cancelled
调试过程：
- 设备管理器能识别ST-Link -> USB和驱动正常
- Keil Settings里能看到ST-Link序列号和固件版本 -> Keil和ST-Link通信正常
- 但SW Device显示 No target connected -> ST-Link连不上STM32芯片
- 检查f103.ioc，PA13/PA14配的是Serial_Wire，调试口没被占用 -> 软件配置没问题
- STM32板子电源灯亮 -> 供电正常
- SWDIO/SWCLK/GND/3.3V接线顺序确认没错 -> 表面看接线正常
- 降时钟频率到100kHz、under Reset模式按复位键，还是No target connected
- 最后换了杜邦线，立刻下载成功
原因：杜邦线内部断线或接触不良，外表看不出来
解决：更换杜邦线
