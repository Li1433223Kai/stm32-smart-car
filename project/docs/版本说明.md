# 版本说明

## v1.0（2026-08-17~08-28）

智能循迹小车基础版正式完成。基于一块插在面包板上的 STM32F103C8T6，用 12V 锂电池 + DCP3512 电源模块供电，采用 TB6612 双路电机驱动、8 路数字灰度传感器和编码器反馈，实现速度环 PI + 位置环 P 双闭环差速循迹。编码器 4 倍频每圈 1040 脉冲，10ms 采样测速；串口输出 VOFA+ FireWater 格式，方便实时调参看波形。

## v1.1（2026-08-28）

代码加入 OLED 显示功能，实时显示状态、实际速度、目标速度和 pos。OLED 驱动用硬件 I2C1 重映射（SCL=PB8，SDA=PB9），显示坐标按行/列（4 行 16 列）。（但是oled屏幕烧坏了）

## v1.2（2026-08-29）

加入独立按键控制（PA8 上拉，bsp_key.c/h）：非阻塞 50ms 去抖 + 沿检测，用于控制小车启停/状态切换。

## v1.3（2026-08-31）

状态机重构：把循迹逻辑改成显式状态机 IDLE/RUN/LOST/CROSS（app.c 的 App_State_Update 每 10ms 调度）。上电默认 IDLE 停车，按 PA8 进 RUN；循迹中全白切 LOST、全黑切 CROSS 并停车。修复两个关键坑：全黑/全白要先判 pos 再跑位置环（否则轮子疯转）；上电 200ms 内忽略按键（否则上电误进 RUN）。

## v1.4（2026-09-01）

小改进：
- 编码器引脚（PA0/PA1/PB6/PB7）改为上拉输入，信号线虚接时计数不乱跳
- 新增 Motor_BrakeAll()，LOST/CROSS 刚进入时快速刹车一次
- LOST/CROSS 状态下按 PA8 可回到 RUN 重新起步，丢线/十字停车后不用断电重启

## v1.5（2026-09-11~09-12）

刹车可靠性修复与测速改造：
- 刹车机制重做：s_brake 保持标志 + 转移当拍执行，速度环短路不再覆盖刹车（修复前 Motor_BrakeAll 是死代码，从未真正生效）；实车验收通过（快甩-松手判据），LOST/CROSS 按 PA8 原地恢复实测通过
- 显示快照改为每拍更新，丢线/停车后串口与 OLED 能看到 9999/-9999 哨兵值
- pos 由状态机读一次后传参进位置环，每拍省约 0.5ms
- 编码器测速改用实测采样间隔 Δt，不再假设固定 10ms；CONTROL_TICK_MS 归 main.c 独立定义，ENCODER_SAMPLE_MS 删除
- 更正 bsp_motor.c 中 TB6612 真值表错误注释（IN1=IN2=1 无论 PWM 均为短接刹车）
- 旧 OLED 屏损坏期间，OLED 初始化与刷新暂注释（2026-10-16 恢复，见 v2.2）

## v2.0（2026-09-23）

RTOS 阶段起点：把 FreeRTOS V9.0.0 源码并入工程、搭好环境。业务逻辑没动，跑的还是原来的裸机前后台主循环，循迹仍是速度环 PI + 位置环 P 双闭环。具体做了：内核选官方 V9.0.0，port 层用 `RVDS/ARM_CM3`，堆用 heap_4，`configTOTAL_HEAP_SIZE` 定 10KB；Keil 分组重排（BSP / FreeRTOS / Port / Heap）并补 IncludePath；新建 `BSP/FreeRTOSConfig.h`；删掉 `stm32f1xx_it.c` 里 SysTick/PendSV/SVC 三个 handler，交给内核接管向量表，`HAL_IncTick()` 移进 `vApplicationTickHook`。顺带把项目纳入 git 管理。

## v2.1（2026-10-10）

控制逻辑从裸机搬进 RTOS 任务：`main` 里 `while(1)` 那三行（编码器更新、状态机、速度环）整体搬进 `controlTask`，用 `vTaskDelayUntil` 锁 10ms 周期，原来的 `while(1)` 清掉。此时整个工程就 controlTask 一个任务，串口打印仍在它内部同步 `printf`，每 500ms 一帧、约 4ms 的阻塞直接算在当拍里。两项验收都过：架空的循迹功能回归（IDLE / RUN / LOST / CROSS 切换 + 刹车），节拍 100 拍 = 1000 tick（自己量自己，只能说明周期锁得住）。

## v2.2（2026-10-15 ~ 10-16）

OLED 显示恢复，驱动从硬件 I2C1 改走软件模拟 I2C，引脚换到 PB3/PB4。PB8/PB9 已被旧屏那次的 12V 打穿，硬件 I2C 在这块板上也没有别的落点可用。串口打印拆出 uartTask，OLED 显示拆出 displayTask，都排在控制任务之后。字模整表换成 VGA 8x16 点阵，4 行文本之间有了行距；控制任务里不再有阻塞式 printf（改成 snprintf + Uart_Send 入队）和每帧全屏清屏（改成整行覆盖）。验证：控制节拍仍是 100 拍 = 1000 tick；显示任务单帧实测 133ms，200ms 一帧。
