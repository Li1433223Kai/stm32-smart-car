# 硬件连接

## 电机（TB6612 双路，D153C）

电机 A 是左轮，电机 B 是右轮。

- 电机A（左轮）：PWMA = PB1，AIN1 = PB10，AIN2 = PB11
- 电机B（右轮）：PWMB = PB0，BIN1 = PB12，BIN2 = PB13

电机驱动的 VM 接 DCP3512 的 12V 输出，STM32 板子由 DCP3512 的 5V 供电，STBY 跳线帽接 D153C 上的 3.3V。

## 按键（启停）

- PA8 = key，**上拉输入**，按下接地（GPIO_PULLUP）
- 软件里做 50ms 去抖 + 沿检测（bsp_key.c），上电后 200ms 内忽略按键，防上电抖动误触发

## 灰度传感器（8 路数字）

- AD0 = PA2，AD1 = PA3，AD2 = PA4
- OUT = PA5

VCC 用 DCP3512 的 5V 输出。探头离地大概 18mm 效果最好，这个距离很关键，太近太远都会误判。

## 编码器

- 左编码器：A相 = PA1，B相 = PA0，定时器 TIM2
- 右编码器：A相 = PB6，B相 = PB7，定时器 TIM4

注意：左编码器 A/B 相接反了（A=PA1, B=PA0），这个接法下计数方向是正的。要是调的时候发现方向反，就把 A/B 对调，或者改方向判断。

## 串口（USART1）

- TX = PA9
- RX = PA10

波特率 115200。

## OLED（0.96 寸，SSD1306，4 针 I2C）

- SCL = PB8（I2C1 重映射）
- SDA = PB9（I2C1 重映射）
- VCC = 3.3V（**千万别接 5V/12V**，会烧片）
- GND = GND

I2C 设备地址 0x3C。CubeMX 里把 I2C1 重映射到 PB8/PB9（I2C1 默认 PB6/PB7 被右编码器占用，所以重映射）。

**注意：** 一定接 3.3V。这块屏我上次接到 12V 直接烧了，万用表量 VCC-GND 变成短路。

## 其他

- LED = PC13
- 调试口（SWD）：PA13（SWDIO）/ PA14（SWCLK）

## 供电系统

```
12V 锂电池 ──→ DCP3512 电源模块 ──→ STM32 板子 / 电机驱动 / 灰度传感器
```

DCP3512 输入 12V，输出有 4 路 3.3V、4 路 5V、4 路 12V、4 路 ADJ（可调）。板子和灰度用 5V 那路，电机驱动的 VM 用 12V 那路。灰度 VCC 要 5V，别接 3.3V。

|---|---|---|---|
| 左电机 | PWMA | PB1 | TIM3_CH4 |
| 左电机 | AIN1 / AIN2 | PB10 / PB11 | 方向 |
| 右电机 | PWMB | PB0 | TIM3_CH3 |
| 右电机 | BIN1 / BIN2 | PB12 / PB13 | 方向 |
| 左编码器 | A相 / B相 | PA1 / PA0 | TIM2 编码器模式 |
| 右编码器 | A相 / B相 | PB6 / PB7 | TIM4 编码器模式 |
| 灰度 | AD0 / AD1 / AD2 / OUT | PA2 / PA3 / PA4 / PA5 | CD4051 选通 + 数字输出 |
| 按键 | key | PA8 | 上拉输入，按下接地 |
| 串口 | TX / RX | PA9 / PA10 | USART1，115200 |
| OLED | SCL / SDA | PB8 / PB9 | I2C1 重映射，3.3V |
| 指示灯 | LED | PC13 | 板上 LED |
| 调试口 | SWDIO / SWCLK | PA13 / PA14 | SWD
